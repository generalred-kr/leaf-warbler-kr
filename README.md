# 솔새과 동정 알고리즘

> 동정 알고리즘(도표) 원작: **김동우** · 웹 앱 제작: 이 저장소 소유자

한국에서 관찰되는 솔새과(Phylloscopidae) 17종을 윙바(날개선) 형태와 몇 가지 형질을 기준으로
단계별 예/아니오 질문을 따라가며 동정하는 필드용 웹 앱입니다.

## 특징

- 날개무늬(윙바) 형태로 세 그룹(A/B/C)을 먼저 나누고, 이후 예/아니오 질문으로 좁혀갑니다.
- 각 질문에 버튼으로 답하거나, 🎤 버튼으로 "예"/"아니오"를 음성으로 답할 수 있습니다
  (Web Speech API 지원 브라우저에서만 동작하며, 자유 서술 인식은 지원하지 않습니다).
- 종이 확정되면 해당 종의 eBird 페이지로 바로 연결됩니다. 링크는 국명이 아니라
  학명(Phylloscopus + 종소명) 기준으로 대조해 연결했습니다.
- 진행 상황(무엇을 어떻게 답했는지)이 화면 상단에 표시됩니다.

## 사용 방법

`index.html` 파일 하나로 동작합니다. 별도 빌드 과정이 없습니다.

- 로컬에서: 파일을 더블클릭해서 브라우저로 열면 됩니다.
- GitHub Pages로 배포: 이 저장소의 Settings → Pages에서 브랜치를 지정하면
  `index.html`이 자동으로 첫 페이지로 서비스됩니다.

## 원본 자료 및 한계

이 앱의 동정 트리(솔새과 동정 알고리즘 도표)는 **김동우**님이 만드신 자료를 바탕으로
디지털화한 것입니다. 도표 제작자에게 사전 허락을 구하지는 못했으며, 원본 도표에
별도의 저작권 표시는 없었습니다. 원저작자를 밝히는 것이 맞다고 판단해 이 자리에
명시합니다. 문제가 있다면 알려주시면 바로 조치하겠습니다.

작성 과정에서 다음과 같은 점을 확인했습니다.

- 표의 일부 하단 세부 분기(솔새사촌류 등)는 원본에 글로 된 구분 기준이 없고 O/X 표시만
  있어, 임의로 질문을 지어내지 않고 원본 구조를 그대로 반영했습니다.
- eBird 링크는 국명이 아닌 학명을 기준으로 대조해 연결했습니다. 일부 종은 국내에서
  쓰는 이름과 eBird의 영문 표준명이 다를 수 있으나(예: 히말라야산솔새 = Claudia's Leaf
  Warbler), 학명이 일치함을 확인했습니다.
- 표를 옮기는 과정에서 몇 차례 오류가 있었고, 스크린샷을 다시 확인하며 수정했습니다.
  혹시 남아 있는 오류를 발견하면 이슈로 남겨주세요.

## 기술 스택

순수 HTML/CSS/JavaScript로만 작성되어 있으며 외부 라이브러리 의존성이 없습니다.
